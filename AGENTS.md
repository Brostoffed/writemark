# Repository instructions

Write prose in ASD-STE100 Simplified Technical English.
Use American spelling, active voice, and short sentences.
Use one name for each thing.
Do not use contractions or semicolons.

## Complete changes

For editor fixes, features, build changes, or release work, use the
[writemark-change-completion skill](.agents/skills/writemark-change-completion/SKILL.md).
Read the skill before edits.
Complete its local steps before the final response.
Do not wait for a separate request about the changelog or version.
Keep unrelated changes intact.

Use existing user authorization for local fixes, metadata, builds, and tests.
Create a pull request or publish only when the user requests it.
Report local checks, pending browser checks, and publication status separately.
